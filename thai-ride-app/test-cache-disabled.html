ทดสอบ Cache Disabled

ตรวจสอบว่า Browser Cache ถูกปิดแล้วหรือยัง

📊 สถานะ Cache

วิธีตรวจสอบ:

  1. เปิด DevTools (กด F12 หรือ Cmd+Option+I)
  2. ไปที่แท็บ Network
  3. เช็คช่อง "Disable cache" ที่ด้านบน
  4. รีโหลดหน้านี้ (กด Cmd+Shift+R)

❌ ถ้า timestamp ไม่เปลี่ยน = Cache ยังทำงานอยู่
