🎯 Visual Guide: Disable Browser Cache

ทำตามขั้นตอนเหล่านี้เพื่อแก้ปัญหา viewCustomerHistory function

1
เปิด DevTools

กดปุ่มลัดเพื่อเปิด Chrome DevTools:

Mac: Cmd + Option + I
Windows: F12
DevTools Location
// DevTools จะเปิดที่ด้านล่างหรือด้านข้างของหน้าเว็บ
✓ Elements | Console | Sources | Network | ...
2
ไปที่แท็บ Network

คลิกที่แท็บ "Network" ใน DevTools:

Network Tab
Elements
Console
Sources
Network
Performance
Filter: All | Fetch/XHR | JS | CSS | Img | Media | Font | Doc | WS | Wasm | Manifest | Other
3
เช็คช่อง "Disable cache"

หาและเช็คช่อง "Disable cache" ที่ด้านบนของแท็บ Network:

⚠️
สำคัญมาก!
ต้องเช็คช่องนี้และเปิด DevTools ไว้ตลอดเวลาที่ทำงาน
4
Hard Reload หน้าเว็บ

กดปุ่มลัดเพื่อ Hard Reload (รีโหลดแบบล้าง cache):

Mac: Cmd + Shift + R
Windows: Ctrl + Shift + R

หรือคลิกขวาที่ปุ่ม Reload → เลือก "Empty Cache and Hard Reload"

5
ตรวจสอบ Network Tab

ดูที่แท็บ Network - ต้องเห็น status code 200 (ไม่ใช่ 304):

❌ ก่อนแก้ (Cache ยังทำงาน)
Name Status Type Size
CustomersView.vue 304 javascript (from cache)
app.js 304 javascript (from cache)
✅ หลังแก้ (โหลดใหม่)
Name Status Type Size
CustomersView.vue 200 javascript 45.2 KB
app.js 200 javascript 123.4 KB
✅
สำเร็จ!
เมื่อเห็น status code 200 แสดงว่าโหลดโค้ดใหม่แล้ว
6
ทดสอบ History Button

ไปที่หน้า Admin Customers และทดสอบปุ่ม History:

  1. ไปที่ http://localhost:5173/admin/customers
  2. หาปุ่มไอคอนนาฬิกา (🕐) ในแถวของลูกค้า
  3. คลิกปุ่ม History
  4. Modal ควรเปิดขึ้นมาพร้อมแท็บ Rides, Deliveries, Shopping
🎉
เสร็จสิ้น!
ถ้า Modal เปิดได้ แสดงว่าแก้ปัญหาสำเร็จแล้ว

🚀 พร้อมแล้ว? ไปทดสอบเลย!

อย่าลืมเปิด DevTools และเช็คช่อง "Disable cache" ก่อนนะ
