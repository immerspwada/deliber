Force Clear Browser Cache

ล้างแคชเบราว์เซอร์แบบสมบูรณ์

⚠️
ทำไมต้องล้างแคช?
เบราว์เซอร์เก็บไฟล์ JavaScript เก่าไว้ ทำให้ปุ่มประวัติลูกค้าไม่ทำงาน ต้องล้างแคชเพื่อโหลดโค้ดใหม่ที่มีฟังก์ชัน viewCustomerHistory
1
เปิด Developer Tools
กด F12 หรือ Cmd + Option + I (Mac) หรือ Ctrl + Shift + I (Windows)
2
คลิกขวาที่ปุ่ม Refresh
คลิกขวา (Right-click) ที่ปุ่ม Refresh ในเบราว์เซอร์ (ต้องเปิด DevTools ไว้ก่อน)
3
เลือก "Empty Cache and Hard Reload"
จะมีเมนูขึ้นมา เลือก "Empty Cache and Hard Reload" หรือ "ล้างแคชและโหลดใหม่แบบสมบูรณ์"
4
รอให้โหลดเสร็จ
เบราว์เซอร์จะโหลดไฟล์ใหม่ทั้งหมด รอจนหน้าเว็บโหลดเสร็จ
5
ทดสอบปุ่มประวัติ
ไปที่หน้า Admin → Customers แล้วกดปุ่มนาฬิกา (ประวัติ) ควรเปิด Modal ประวัติลูกค้าได้แล้ว
✅
กำลังล้างแคชและเปิดหน้า Admin...
